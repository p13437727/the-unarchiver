## 📦 What is The Unarchiver?

**The Unarchiver** is a lightweight archive extraction utility designed specifically for macOS.

It supports many popular archive formats, including:

- 📁 ZIP
- 📦 RAR
- 🗜️ 7-Zip
- 📄 TAR
- 🌀 GZIP
- 📚 BZIP2
- 💿 ISO
- 🗂️ BIN
- And many more

## 🛠️ Set The Unarchiver as Default

To automatically open archive files with The Unarchiver:

1. Select an archive file.
2. Right-click it and choose **Get Info**.
3. Find the **Open with** section.
4. Select **The Unarchiver**.
5. Click **Change All**.

Now supported archive files will automatically open with The Unarchiver.
